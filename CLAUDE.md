# Project Instructions

## Workflow
1. Read the user's request and implement the changes
2. Run the appropriate build command to verify (e.g., `npm run build` or `pnpm build`)
3. If the build fails, fix the errors and try again
4. Make small, incremental commits

## Rules
- Do NOT ask questions. Use your best judgment for any ambiguities.
- Complete the full task. Do not stop partway through.
- Keep the existing code style and patterns.
- Install any additional dependencies you need.
